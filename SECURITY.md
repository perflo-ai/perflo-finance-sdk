# Report a security issue

Report SDK vulnerabilities through [GitHub private vulnerability reporting](https://github.com/perflo-ai/perflo-finance-sdk/security/advisories/new). Do not open a public issue for a vulnerability or include customer credentials, access tokens, financial data, or unmasked account information in a report.

Include the affected SDK version, the operation involved, reproduction steps, and the observed impact. Use synthetic credentials and data in every reproduction.
